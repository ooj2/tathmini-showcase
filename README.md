# Tathmini — assessment to action

**A public project overview by James Otoa.** Tathmini is an offline-first teacher tool for foundational reading and maths assessment. It helps a teacher move from a learner's assessment to a level, a group, and a next teaching action.

**[Explore the public demo](https://tathmini.app/)** — choose **Load the demo class**. Use sample data only; do not enter real learners' names or results.

## What the teacher can do

- Assess one learner through a guided sequence or enter an oral check, CSV scores, or typed scores.
- Maintain a class roster and compare assessment rounds.
- See rule-based diagnostic levels and suggested next teaching actions.
- Plan groups, review coaching notes, and practise making level calls before seeing the rule-based result.
- Work offline after the app has loaded, with records stored on the device until the user explicitly exports them.

The interface includes English and a **draft Kiswahili** translation. Tathmini does not use AI to assign diagnostic levels.

## Current status

This is a demonstration build. Its unsigned sample rules and cut-points are **not validated for field use**. A five-teacher phone pilot is planned but has not yet been completed. The demo does not establish learning impact or field effectiveness.
